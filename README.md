# Interactive Whiteboard

An interactive whiteboard application built using HTML, CSS, and Vanilla JavaScript. The application supports freehand drawing, erasing, sticky notes, image insertion, undo-redo functionality, and board download.

## Features

- Pencil tool for freehand drawing
- Eraser tool
- Sticky notes support
- Image insertion on the board
- Undo and redo functionality
- Download board as an image
- Clean and interactive user interface

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Canvas API

## Concepts Used

- DOM manipulation
- Event handling
- Canvas API
- Frontend design principles
